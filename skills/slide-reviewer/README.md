# Slide Reviewer

技術登壇（LT・カンファレンスセッション）向けのスライドレビュー Skill です。Slidev / Marp などのコードベース資料と PDF を対象に、資料から判断できる範囲で「聴衆に伝わる発表になっているか」を確認します。

## レビュー観点

- **内容レビュー**：聴衆との理解ギャップ、発表の目的、ストーリー、スライド間の接続、時間と情報量の配分、根拠、導入・結論
- **見た目レビュー**：文字・レイアウト・コントラスト、色覚特性や投影環境への耐性、図表・コードの可読性、アニメーションへの依存
- **総合レビュー**：内容と見た目の両面を評価し、優先度付きの改善案を提示

資料だけでは実際の話し方、声、聴衆の反応などは評価しません。録画・音声・実測時間が提供された場合は、資料レビューと区別して追加確認できます。

   https://yoshiko-pg.github.io/talks/zennfes-2026/  
   技術登壇資料の内容構成や伝え方を考える際の参考例として参照。

参考資料はレビュー観点を考えるためのものであり、個々の発表に一律の正解を適用するものではありません。発表の目的、分野、聴衆、会場、持ち時間に応じて判断してください。
